# LLM Gateway — 设计规范

## 配色

| 角色 | 色值 | 用途 |
|------|------|------|
| 背景 | `#FFFFFF` | 页面主背景 |
| 次级背景 | `#F7F7F8` | 分组区域、输入框底色 |
| 卡片 | `#FFFFFF` | 卡片、弹窗，带 1px 边框 |
| 主文字 | `#0A0A0A` | 标题、正文、按钮文字（黑底时） |
| 次文字 | `#6B7280` | 描述、辅助信息 |
| 占位/禁用 | `#9CA3AF` | placeholder、禁用态 |
| 边框 | `#ECECEE` | 分割线、卡片边框、输入框边框 |
| 主按钮 | `#0A0A0A` | 黑底白字，圆角 10dp |
| 成功 | `#10B981` | 在线状态、成功提示 |
| 警告 | `#F59E0B` | 额度不足、降级提示 |
| 错误 | `#EF4444` | 失败、断开 |

## 字体

- 标题：20sp / 600
- 二级标题：16sp / 600
- 正文：14sp / 400
- 辅助：12sp / 400
- 数字/等宽：JetBrains Mono 13sp（用量、Token 数）

## 间距

- 页面边距：20dp
- 卡片内边距：16dp
- 元素间距：12dp
- 列表项高度：52dp
- 底部导航高度：64dp

## 圆角

- 卡片：14dp
- 按钮：10dp
- 输入框：10dp
- 标签/徽章：6dp
- 底部弹窗：20dp（顶部）

## 阴影

不使用大面积投影。仅卡片悬浮态用 `0 2 8 rgba(0,0,0,0.06)`。

## 页面结构

```
启动页 → 登录/注册 → 主框架（底部导航）
├── 聊天（首页）
│   ├── 模型选择条（顶部横向滚动）
│   ├── 消息列表
│   └── 输入栏（底部）
├── 模型（大全）
│   ├── 分类 Tab（全部/对话/图像/代码/嵌入）
│   └── 模型卡片网格
├── 控制台
│   ├── 用量概览（今日/本月 Token、费用）
│   ├── API Key 管理（我的 Key 列表）
│   ├── 渠道配置（上游 Key 池）
│   └── 请求日志
└── 我的
    ├── 账号信息
    ├── 额度/套餐
    ├── 微调任务
    └── 设置
```

## 核心页面说明

### 聊天页
- 顶部：当前模型名 + 下拉箭头，点击展开模型选择面板（底部弹窗）
- 消息：用户消息右对齐黑底白字气泡，AI 消息左对齐白底灰边框气泡
- 输入栏：圆角输入框 + 发送按钮（黑色圆形）
- 支持流式输出，打字机效果

### 模型页
- 顶部搜索框
- 分类 Tab 横向滚动，选中态黑底白字
- 模型卡片：图标 + 名称 + 提供商 + 上下文长度 + "使用"按钮
- 卡片点击进入模型详情（能力说明、价格、参数）

### 控制台
- 顶部用量卡片：本月 Token 消耗（大字）、费用、请求数
- 功能入口网格：Key 管理、渠道配置、请求日志、微调任务
- 每个入口带图标 + 标题 + 简短描述

### 我的
- 头像 + 用户名 + 会员标识
- 列表项：额度中心、微调任务、API 文档、设置、关于
- 退出登录（红色文字，底部）

## 组件规范

### 按钮
- 主按钮：黑底 `#0A0A0A`，白字，圆角 10dp，高度 44dp，无阴影
- 次按钮：白底，黑字，1px `#ECECEE` 边框，圆角 10dp
- 文字按钮：无背景，黑字，14sp

### 输入框
- 高度 44dp，圆角 10dp
- 背景 `#F7F7F8`，聚焦时背景变白 + 1px 黑色边框
- 无下划线样式

### 卡片
- 白底，1px `#ECECEE` 边框，圆角 14dp
- 内边距 16dp
- 列表卡片之间间距 10dp

### 标签/徽章
- 高度 22dp，圆角 6dp，内边距水平 8dp
- 在线：`#ECFDF5` 底 + `#10B981` 字
- 离线：`#F3F4F6` 底 + `#6B7280` 字
- 热门：`#0A0A0A` 底 + 白字

### 底部导航
- 高度 64dp，白底，顶部 1px `#ECECEE` 边框
- 图标 24dp，选中态黑色，未选中 `#9CA3AF`
- 文字 10sp，选中态 600

## 动效

- 页面切换：右滑入 200ms，淡出 150ms
- 底部弹窗：上滑 250ms，弹性减速
- 按钮点击：scale 0.97，100ms
- 流式消息：逐字出现，无闪烁
- 列表加载：骨架屏（浅灰块 + 微光扫过）

## 空态/错误态

- 空态：居中 64dp 线性图标 + 14sp 次文字说明
- 错误态：红色图标 + 错误信息 + "重试"按钮
- 加载态：骨架屏或 24dp 圆形进度条（黑色细环）
